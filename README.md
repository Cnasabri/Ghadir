# غدیر — آلبوم دیجیتال فروش

آلبوم فارسی و راست‌چین پروژه غدیر، گروه ساختمانی زاگرس، بر اساس PDF ارسالی `Ghadir041.pdf` (۳۳ صفحه).

## اجرا

```sh
cd /workspace/Ghadir
python3 -m http.server 8000 --bind 0.0.0.0
```

سایت استاتیک است و به build، کلید API یا سرویس خارجی نیاز ندارد. تمام تصاویر و فونت وزیرمتن محلی‌اند. برای GitHub Pages، فایل‌های همین پوشه را در ریشه ریپو قرار دهید و انتشار از شاخه و پوشه ریشه را فعال کنید. انتشار این نسخه هنوز انجام نشده است.

## امکانات

- ورودی سینمایی، کارت‌های بازشونده، موشن‌های اسکرول با آستانه ۶۸٪ و تکرار پس از خروج کامل.
- گالری کامل ۳۳ صفحه، فیلتر موضوعی، نمایش اصلی با زوم و کنترل صفحه‌کلید.
- پلان هفت طبقه، ۱۸ واحد در هر طبقه، انتخاب در SVG و فهرست جایگزین برای موبایل.
- کارت مساحت، تعداد خواب و طبقه؛ پلان واحد با ماسک مستقل؛ جزئیات و تصویر مشخصات اصلی همان طبقه.
- انتخاب اول واحد را نمایش می‌دهد؛ انتخاب دوباره یا دکمه جزئیات، به بخش واحد می‌رود.
- نقاط معرفی امکانات، چیدمان متحرک تصاویر داخلی، درخواست اطلاعات قابل کپی.
- نسخه موبایل، پشتیبانی از reduced motion، بازگرداندن فوکوس و موقعیت اسکرول بعد از بستن نمایشگر.

## فایل‌ها

- `index.html`: ساختار و متن فارسی.
- `styles.css` و `additions.css`: طراحی و موشن‌ها.
- `app.js`: مشخصات واحدها، مختصات انتخاب، تعاملات و گالری.
- `assets/pages/`: ۳۳ تصویر اصلی استخراج‌شده، بدون کاهش دوباره کیفیت.
- `assets/plans/`: پلان و سند مشخصات مستقل هر طبقه.
- `assets/web/`: تصاویر WebP برای بارگذاری سبک‌تر.
- `prepare_assets.py`: بازتولید تصاویر وب از تصاویر اصلی؛ به Pillow نیاز دارد.

متراژ و تعداد خواب از فهرست مشخصات چاپ‌شده در PDF وارد شده‌اند. بعضی برچسب‌های تصویری پلان با فهرست چاپی اختلاف دارند؛ فهرست مشخصات ملاک کارت‌هاست و سند اصلی در جزئیات نمایش داده می‌شود. تصاویر داخلی به واحد خاص نسبت داده نشده‌اند، زیرا PDF این ارتباط را مشخص نکرده است. اطلاعات تماس و وضعیت فروش درج نشده‌اند چون تأیید نشده‌اند.

پلان مستقل هر واحد، برش ماسک‌شده از پلان طبقه است؛ فایل CAD یا پلان معماری جدید تولید نشده است. مختصات انتخاب ترسیم‌شده و قابل تنظیم در `app.js` هستند؛ برای استفاده فروش نهایی، مالک باید اختلاف‌های سند و حدود دقیق واحد/تراس را بازبینی کند.
