# Conversation brief

## User intent captured from the build conversation

The user wanted a premium English property-sales application inspired closely by two supplied CRM and real-estate dashboard references. The result should feel visually exceptional, motion-rich, and complete rather than like a landing-page mockup.

The user explicitly requested:

- A new project separate from the previously published RealE 360 site.
- Preservation of the previous site and its URL.
- A new NODE-branded interface with a monochrome logo that blends with the background.
- Ghadir project imagery and unit information.
- A left-side visual property scene that opens unit selection and image choices.
- Internal pages, real navigation, working arrows and icons, useful popups, account information, residence information, and a strong sales workflow.
- Counting animations, card and text reveals, image transitions, and polished responsive behavior on tablet and mobile.
- GitHub upload in a new folder rather than replacement of the repository root.

## Final project decisions

- New application name: `NODE — Ghadir Residences`.
- GitHub folder: `node-residences/` in `Cnasabri/Ghadir`.
- The original Ghadir website remains at the repository root.
- The previous RealE 360 Site remains separately deployed.
- Application language is English.
- Original plan annotations remain as supplied.
- Browser-local state is used for favorites, comparisons, contacts, viewings, messages, settings, and backups.
